01 / PROJECT OVERVIEW

Where arguments meet AI

01

An interactive debate platform for challenging ideas, defending viewpoints, and evaluating arguments.

Voice-Versus brings AI-powered argument exchange and multiplayer debate interaction into one web application. Users can choose to debate an AI opponent or participate in a debate with another person.

In User vs AI mode, the AI responds to what the user says or presents, continuing the exchange in a debate-like manner. In User vs User mode, two participants debate a selected topic, and an AI judge provides a detailed evaluation report.

The project combines a React interface, a FastAPI backend, and integrations with Groq and Deepgram.
